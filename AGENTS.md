# AI Project Contract

Binding for agents in this repository.

## Before editing

- Read this file, README, CONTRIBUTING, DESIGN.md, `git status`.
- Work on a topic branch. Do not commit to `main`.
- Do not invent biography, emails, or a second visual world.

## During editing

- Smallest coherent change.
- Identity belongs in `lonefox.config.ts`. Tokens belong in `src/styles/global.css`.
- Do not rearrange rooms, post-nav, or archive shelves.
- Do not add Tailwind, React, a theme marketplace, or a second accent color.

## Before commit

- `npm run check && npm run build`
- Conventional Commit: `type(scope): imperative summary`
- Push the branch. Open a PR. Do not push `main`.
